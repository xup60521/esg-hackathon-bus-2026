## 重建與限制
【事實】全期重建 72,975 個 run，平均 2.65 個有人上車到站；重建到站 193,637 次，既有到站檔 193,715 次，差 -78 次（總量比 99.960%），未逐筆配對。缺站序、同站、旅次小於 180 秒或大於 4 小時者排除。
每車每日依刷卡時間排序，方向依上下車站序；方向反轉、站序倒退或相鄰刷卡間隔超過 90 分鐘切 run，同站視為遞進。起始時間是首筆刷卡時間，run 子路線取首筆。上車前載客以同車同日尚未下車旅次計數，時間同秒先處理下車；同站連續刷卡相隔至多 10 分鐘合併。站序遞增往日月潭（outbound），遞減往臺中（inbound）。不同車的同秒起始不判先後。
班次是刷卡推估，可能分裂或合併真實班次，缺少無人刷卡班次、現金、漏刷及未上車乘客。無車型對照，兩種席數皆為情境，載客重建異常不可作超載指控。部分前一班在下一班起始後才達門檻，條件機率是回顧性關聯；操作提示只計事前已觀察到者，兩者不可直接等同。窗口基準及日重抽不修正未觀察班次或重建誤差。
【推論】條件機率與窗口基準的差異尚無配對不確定度檢驗，不能宣稱前一班提供額外資訊，也不能直接推導調度效益。
