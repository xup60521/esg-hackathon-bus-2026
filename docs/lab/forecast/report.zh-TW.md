# 離線每日刷卡搭乘量預測與時間回測

研究及執行日期：2026-11-04。基準 HEAD：`5861d0651eed3c9bd898bd5fd76ab1d18c19de5f`。只讀本地彙總，沒有連線資料庫、傳送乘客資料、修改 UI 或共享路由。

## 摘要

2024 年驗證期選出的四週同星期中位數，在 2025 年共同可評估的 336 日，MAE 為每日 291.53 人次，WAPE 為 11.28%。相同日期的上週同日基準 MAE 為 352.33，選出模型降低 MAE 約 17.26%。這不是準確率或營運改善幅度。

選出模型的尖峰低估量占比為 12.75%，高於上週同日基準的 10.49%。若用於尖峰備車，不能只按平均誤差選擇。刷卡只記錄成功搭乘，不能推估完整需求、候車或拒載。

## 資料盤點

讀入 24 份 `data/midstop-months/*.json`，共 292,562 筆站點小時彙總。七欄是日期、支線、方向、站點、小時、上車、下車。上車與下車各 1,800,910 人次，每一彙總鍵與 `public/data/midstop.json` 完全一致。上下車不能相加當成旅次數。方向由既有程式依站序推定，沒有另做營運方向驗證。

觀測窗是 2024-01-01 至 2025-12-31，時區 Asia/Taipei，共 731 日，有上車紀錄 725 日。缺日為 2024-07-24、2024-07-25、2024-10-02、2024-10-03、2024-10-31、2025-07-07。原因未查證，不能標成停駛、颱風或零需求。有紀錄日也可能不完整。

方向未知共 6,281 上車人次，占 0.3488%，保留獨立群組。輸出每日總量、3 個方向、6 個支線，共 10 組邊際序列；方向可加回總量，支線可加回總量，不能把兩套分組一起加總。6670H 沒有併入其他支線。

6670E 只有 427 日有正上車紀錄，其餘 304 日原因未知；unknown 方向有紀錄 721 日。沒有正上車紀錄的分組日期保留 null，即使有下車事件也不推定零上車。沒有班表或完整性標記，無法辨認零搭乘和資料缺失。

## 方法

只用 Python 標準函式庫，無新套件、網路請求或隨機程序。所有預測只讀目標日前的實際值，缺任一必要歷史就不出預測，不填零或向前填值。

| 模型 | 預測公式 |
|---|---|
| seasonal7 | 上週同星期 y[t−7] |
| weekday_mean4 | 前 4 週同星期平均 |
| weekday_median4 | 前 4 週同星期中位數 |
| mean28 | 前 28 個日曆日平均 |

這些是週季節基準。只有兩年資料，未建模年度季節、春節移動或活動效應，沒有訓練 AI 模型。

2024 年前半年提供初始歷史，2024-07-01 至 12-31 為模型選擇期。各組依四模型共同有效日期的最低 MAE 選擇，至少需要 28 個驗證日。平手依固定模型順序。選擇到此凍結，2025 年為保留測試年。每日先預測再揭露實際值，下一日可使用前一日已揭露值；不是年初一次預測全年。

資料延遲未知，回測假設前一日彙總在預測前可取得。如果實際延遲超過一天，必須重做相應的延遲回測。

主要比較限定所有模型共同有效日期。28 日平均遇缺日後連續 28 日無法預測，因此共同樣本較少。另提供 `individualSupportMetrics`，呈現每個模型全部可評估日期，因日期不同不可直接公平排名。

MAE 是平均絕對誤差，RMSE 是均方根誤差，WAPE 是絕對誤差總和除以實際人次總和，bias 是預測減實際的平均。實際總和為零時 WAPE 為 null，不產出「100% 減 WAPE」準確率。尖峰門檻使用各組 2024 年有紀錄日第 90 百分位並固定；尖峰低估量占比為尖峰日 max(實際−預測,0) 總和除以尖峰實際總和，不是拒載比例。

## 實際結果

總量共同驗證 96 日，測試 336 日。2025 年有紀錄 364 日，主要比較排除缺實際的 1 日及缺必要歷史的 28 日。選出模型本身可評估 360 日，在這些日子的 MAE 為 293.74、WAPE 為 11.52%。以下主要比較使用相同的 336 日。

| 總量模型 | 驗證 MAE | 測試 MAE | RMSE | WAPE | bias | 尖峰低估量占比 |
|---|---:|---:|---:|---:|---:|---:|
| seasonal7 | 240.25 | 352.33 | 481.95 | 13.63% | -10.41 | 10.49% |
| weekday_mean4 | 200.32 | 298.84 | 407.54 | 11.56% | -18.09 | 12.61% |
| weekday_median4 | 196.87 | 291.53 | 402.82 | 11.28% | -22.47 | 12.75% |
| mean28 | 376.11 | 418.05 | 513.08 | 16.18% | -14.42 | 22.54% |

總量尖峰門檻為每日 3,142 人次，測試共同樣本有 55 個尖峰日。預測保留小數，計算誤差前不四捨五入。

## 產物與整合

- `public/data/lab/forecast/summary.json` 提供品質、協定、模型選擇、逐月誤差、各模型個別覆蓋率及輸入 SHA-256。
- `public/data/lab/forecast/results.json` 再加每日序列與逐日回測。null 與 `commonSupport` 表示缺資料或無法公平比較。沒有卡號、個人旅次、站點小樣本。
- `src/features/lab/forecast/data.ts` 只有 TypeScript 型別及資料路徑，供主代理交 Claude 建立 UI。型別不是執行時 JSON 驗證器。建議先載 summary，按需取 results；不需新增 API 或依賴。
- `historicalNextDay` 是以 2025-12-31 為起點的 2026-01-01 歷史示範，總量點估 2,367.5。尚無真值驗證，也沒有元旦特徵；必須保留 `historical_demo_not_current_forecast`，不可展示成今天或明天的預測。
- `docs/lab/forecast/run-output.json` 保存真實建置輸出，`validation.txt` 保存測試與重跑雜湊。

## 驗證與重現

從 checkout 根目錄執行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 scripts/lab/forecast/build.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts/lab/forecast -p 'test_*.py' -v
sha256sum public/data/lab/forecast/*.json
```

實際執行 5 個 unittest 全數通過。驗證日曆落後值、缺資料拒絕預測、當日及未來值不影響預測、中位數處理極端值、零分母、誤差符號、跨月合併、檔內重複鍵拒絕、真實資料逐鍵對帳、方向及支線守恆、每月樣本加回全年、缺日影響後續窗口、選模只依驗證 MAE。

輸出不含執行時戳，固定輸入可逐位元重現。兩次建置雜湊一致，見 validation.txt。建置拒絕不合法欄數、日期、小時、負數／非整數人次、重複鍵與公開彙總不一致，輸出只能在授權 forecast 資料目錄下。未跑全站 build、UI 或 TypeScript 專案檢查；沒有修改 UI、依賴或共享路由，同 checkout 其他方向仍有寫入。

## 限制與後續

刷卡只能觀察成功搭乘；不能推出完整需求、候車分鐘、拒載、容量或應加開幾班。沒有班表、票證涵蓋率與資料到達時效，無法排除模型學到供給限制或資料收集差異。

沒有有效的預測區間、節慶特徵、近期資料、外生天氣預報及活動資訊。應先補齊缺日原因、班表容量、近期完整資料及資料延遲，再於新的保留期間評估節慶模型與區間涵蓋率。不能把 2025 年回測直接用於現行排班。
