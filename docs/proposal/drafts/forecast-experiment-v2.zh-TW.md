# 中途站載客預報：門檻與排序實驗

合併規則預先固定：桃米坑和暨南大學依 `public/geo/stops.json` 座標相距約 1.1 公里，合併為中途站群；其他兩站不合併。各站仍各自建模，群組將兩站的到站預測合併，選同一群組門檻；每站到站各算一筆，不視為獨立班次。

訓練資料為 2024-01-01 至 2025-03-31；2025-04 至 06 為門檻選擇集；2025-07 至 12 為留出集。每個座位情境的事件定義為站前載客至少座位數減五。預測使用上游載客及訓練期歷史平均；模型、歷史平均及門檻皆未使用留出集重新擬合。選擇集按分數排序，在警示不超過預算下取最低門檻，分數相同一律不跨越預算，套用留出集時不再調整。預算只約束選擇集，留出期比例可能超標。

以下區間是 300 次以日期為單位重抽的 95% 百分位區間，固定模型與門檻；不含訓練及門檻選擇的不確定性。假警報率為假警報除以全部負例。提前時間只計正確警示，為上游最後刷卡至目標站第一筆刷卡的時間差。精確率、召回率或提前時間分母為零時未定義；區間只用有定義的重抽樣本，次數見 JSON。
