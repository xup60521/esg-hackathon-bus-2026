## 第十四輪後修補

- §10 已把既有做法與本案待驗差異並列，也明寫不主張首創。表格可幫評審理解定位，但索引來源、未取得全文與現場比較尚未完成，不能把表格當作增量證據。主張句及元件表、對照表有少量重複，仍可接受。
- §9 區分每經站車次事件率與成功刷卡旅次暴露，定義人次比，並承認年經站車次待業者班表及現場確認。兩種口徑不再被暗示可以互換；但用現場率乘全年車次仍須先證明時段、站點及日類具有代表性或適當分層，且人次比須有事件、可觀測性與不確定度，否則不能當全年估計。h 表仍是無觀測依據的情境，不是預測。
- §9 補列 d 與 b，與附錄 F 的範圍一致。24–32 人的門檻對應 §4 的每人 30 人公里及 80 車公里算例，不適用所有列出的 d 值；目前同句排列容易讓人誤讀。
- PLAN 與 README 都標為 v5.6、第十三輪後，彼此一致；既然內容已有第十四輪後修補，「第十三輪後」不能清楚辨識目前修訂，建議更新修訂說明而非暗示審查已全部完成。
- §6 新增 G 研究軌，指出時程、人力及獨立資源待協商；A、G 也保留重疊站日計入 G0、總計不超過 16 站日的限制。路線表「不計入 G0 上限」若單獨閱讀，易與重疊站日規則衝突，應改成獨立研究的非重疊站日不計入。研究軌未凍結、未註冊，不能算既定交付。

未見足以推翻提案的新增矛盾或已證明成效的誇大。主文的警語及樣本、人力數字仍密集，尤其 §3、§6、§9；適度把細算留在附錄，可減輕快讀負擔，但核心限制應保留。
