# 第十七輪獨立評審

以一般黑客松、具競爭力且可入圍為評分情境，對照第十五輪 Terra 的 8／7／7／7，審閱目前主文、README、相關附錄及第十六輪意見。這是文件審查，未重跑資料、操作展示或核實外部文獻；官方權重未知。

## 修補檢查

- §10 對照表已涵蓋多種先例，區分既有概念與待驗增量，並註明 Tan & Ramli 全文未取得及不主張首創；沒有把比較寫成已證明的優勢。元件表、假說段落及對照表略有重複，仍可閱讀。
- §9 的 31,187 是同車同日同站去重的嚴格下限，44,969 是十分鐘切段估計，兩者均漏掉零上車過站。附錄 F 已明言後者不是實際車次上限，並列範圍與過濾條件。但主文把兩者寫成「基底區間」並乘以情境率，容易誤認為全年總經站車次及事件數的上下界；即使 p 已註明無觀測依據，也應在主文直接說明該區間不是上限或信賴區間。水社與向山的路線範圍仍待確認。由現場率推估全年還需時段、站點及日類的代表性或分層；人次比也受追蹤可觀測性與不確定度限制。
- d 在主文、D、F 已一致寫為每位轉移者避免的自用車公里，係數為 kg／人公里；24–32 人對應 §4 的 d＝30、80 車公里算例，§9 緊接列出其他 d 值仍可能使讀者誤以為門檻通用，宜在同句重申算例條件。
- PLAN 與 README 均為 v5.7、第十五輪後，README 亦列第十六輪，彼此基本一致；版本說明未明示第十六輪後的修補，辨識性仍可改善。
- §6 路線圖說 G 研究軌「不計入 G0 上限」，但下文和附錄規定重疊站日也計入 G0。單讀表格仍有矛盾，應限定非重疊站日。§3、§6、§9 數字和限制密集，可把細算移至附錄，保留決策條件及必要限制。
