# 附錄 B｜站日觀察紀錄表

每次經站一列，無候車或不停靠也記錄；未知填「?」，零才填 0。站日、方向、窗口、觀察員代碼及天氣填表首。班次依班表配對，無法配對記未知；車牌末碼僅在必要且核准時記錄，不抄完整車牌。

| 欄位 | 記法 |
|---|---|
| 抵站時間、班次、方向 | 實際時分、班表識別及行車方向 |
| 車牌末碼、座位型式 | 可選末碼；型式或未知，不猜座位數 |
| 候車、上車、因客滿未上車 | 抵站前候車數、該車上車數、因容量不足留站人次 |
| 改等下一班、離站放棄 | 該次留站者在觀察期間之可見後續；未知另記，不能強加總 |
| 司機按鍵事件 | 依事後營運紀錄配對，記有／無／未知與事件時間 |
| 備註 | 不可觀察、車輛未停、異常與修正原因 |

過站是車輛經過而未停靠；只有可確認候車且因滿載不能上車才是滿載過站。留站是因該車容量不足未上車，包含停站後部分上車；放棄是觀察期間離開候車處且可確認不再等該線，原因未知不可推定。重複留站是同一人在同一觀察窗口連續遭不同車次留站，只有持續可見才記；無法確認記未知。

觀察員先共同閱讀定義、演練範例並獨立編碼，分歧討論後再正式觀察。事先抽選站日及車次，由兩人各自獨立記錄、不互看；逐車核對滿載事件是／否，報一致率及 Cohen's kappa，提案目標 κ≥0.8；稀少事件導致 κ 不穩時同報列聯表與分母。未達目標先釐清定義、重訓並再抽查，原始紀錄與裁定分開保存。

不拍臉、不錄影、不記姓名、電話或其他個資；臨時追蹤序號窗口結束即銷毀。紙表上鎖、電子表限權加密，提案保存 90 日後刪除，實際期限須依法與業者核定；僅公布去識別彙總。觀察員站在安全候車區，不站車道、不攔車、不干擾司機或乘客。司機僅於安全且法規允許時按鍵，不能安全操作時停妥後補記實際站點與事件時間；保留補記標記，不以按鍵位置直接代替事件位置。

## 選填欄位：無障礙空間需求

每站日加記「需無障礙空間（含輪椅使用者；定義待乘客代表確認）的候車者未上車人次」及其候車人次分母。不記身分、不記障礙類別、不拍攝；格內人數少於 5 時抑制不報。此欄僅供公平檢視，不能推論個人身分或待遇差異；紀錄方式須與業者、乘客代表另行約定。
