## 限制（務必揭露）
1. **回顧性**：旅次篩選（排除同站與乘車時間不在 3 分鐘至 4 小時者，1,800,910→1,786,330 筆）、方向（由旅次的下車站推定）、班次邊界、離站時刻（最後一筆刷卡上車）與目標在車人數，都用事後的完整旅次重建；上線需車機／GPS 與即時刷卡驗證（G1）。
2. 看不到被留下的人、現金、漏刷與無人上車的過站；客滿而無人上車的站不在資料內，盛行率可能偏低。
3. 提前量使用直線距離與固定速度，僅為近似。
4. 車牌與車型對照未取得，41／37 席為兩種情境；重建在車人數偶有超過官方容量，屬重建誤差。
5. 服務站集合由刷卡資料推得，不是班表；班表到手後須核對。
6. 規則 R 在逐站表使用固定門檻（載客 ≥ 席數−5），在每日提示預算表中則掃描選擇期分數以符合平均預算，是兩種不同的門檻；`max_alerts_in_a_day` 為截斷前計數。
7. 留出期實際有資料的日期為 183 日（2025-07-07 無刷卡）。
