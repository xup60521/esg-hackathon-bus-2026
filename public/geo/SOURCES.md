## Notes

- `terrain-height-768.i16`: raw little-endian Int16 heights (m), 768×726, row-major north→south, area-averaged from `terrain-elevation.png` by `build_heightmap_bin.py`. The browser builds the terrain mesh from this file instead of decoding PNGs through a canvas, because privacy-hardened browsers add noise to canvas reads (±256 m spikes with Terrarium encoding).
- `terrain-texture-light.webp`: light-theme variant of the stylized texture (`build_terrain_light.py`), same grid and sources as the dark one.
- Regeneration order: `build_terrain.py` → `build_terrain_light.py` → `build_heightmap_bin.py` (each merges its keys into `terrain.json`).

- **Route paths are road-routed, not official bus shapes.** The official TDX `BusShape` API for route 6670 requires an
  API key, so paths are OSRM/OpenStreetMap driving routes between consecutive official stop coordinates
  (one route per unordered stop pair found in `data/trips.csv`, reversed for the opposite direction).
  They approximate, but may differ from, the real bus alignment (OSRM snaps stops to the nearest road; the
  real bus may use different roads).
- The texture's Sun Moon Lake water polygon is detected from flat, equal-elevation cells of the DEM (surface ≈ 745–746 m
  in this DEM, not the 748 m nominal level), and is a rendering aid only.
- Terrain elevation PNGs use Terrarium encoding (`m = R*256 + G + B/256 - 32768`), quantised to 1/8 m; sea/nodata = 0 m.
  `terrain-elevation-1024.png` is the exact 2×2 area average of the 2048 grid (same bounds).
- Township shapefile CRS is GCS_TWD97[2020] and the DEM is TWD97 TM2; both are treated as WGS84 (differences are well under the
  simplification tolerances).
- Regenerate: see the usage line at the top of each script in `scripts/geo/` (run with `uv run --with ... python -I`).

### Roads (`roads.json`, `road-labels.json`)

- Format: `{"classes": ["freeway","expressway","provincial","county","local"], "lines": [[classIndex, [[lon,lat],...]], ...]}`
  ordered major → minor; an extra `attribution` string is included. Coordinates rounded to 5 decimals, lines merged
  and simplified (≈ 10 m for freeway/expressway, 15 m provincial, 20 m county, 30 m local).
- **Mixed provenance, by class.** The only official vector road data that can be downloaded without registration is the
  nationwide 國道/省道/快速公路 centreline (NLSC) plus the 臺中市政府 road centreline (Taichung only). There is **no**
  registration-free official vector file for 縣道/鄉道 (TDX needs an API key; 公路局 only publishes 省道 route tables; the
  NLSC e-shop lists only 國道/省道). Therefore:
  - `freeway` (國道 incl. interchanges/ramps = ROADCLASS1 HW/HU), `expressway` (快速公路 台61/74/76 = 1E),
    `provincial` (省道 = 1U/1W): **official, NLSC**.
  - `county` (縣道: numeric `ref` on secondary/tertiary ways) and the OSM part of `local` (鄉道/區道: `ref` prefixed
    投/中/彰/苗/雲, excluding 專用道/農路): **OpenStreetMap fallback (ODbL)**; parts within ~12 m of an official line
    are removed to avoid duplicates.
  - The Taichung part of `local` (named roads ≥ 20 m wide with level 1–3, not already covered above): **official,
    臺中市政府**.
- `freeway`/`expressway`/`provincial` carriageways are separate lines where the source draws dual carriageways, so the
  total length counts both directions. The NLSC data splits routes at interchanges, so route pieces are short.
- `road-labels.json`: `[{name, lon, lat, cls}]` route numbers (國1, 台21, …) placed at the midpoint of centreline pieces
  (≥ ~12 km apart per route), `cls` = index into `classes`.
- **Baked streets**: all 臺中市政府 centreline segments not already drawn as vector (≈ 100 k segments, mostly inside
  臺中市) are drawn as pale 0.5–1.5 px hairlines (34 % opacity) into `terrain-texture.webp`. Outside 臺中市 (南投縣,
  彰化縣, 苗栗縣) no minor streets are baked since no official vector file was available.

### Districts

- `district-labels.json`: `[{town, county, lon, lat, area_km2}]` — pole of inaccessibility (shapely `polylabel`, computed
  in TWD97 TM2 metres) of the largest part of each township *clipped to the bbox*; `area_km2` is the township's full
  area (TM2). Townships with < 1 km² inside the bbox get no label.
- `county-labels.json`: `[{county, lon, lat}]` for counties with ≥ 10 km² inside the bbox (苗栗縣 has only 9 km² and is
  omitted).
- `counties.geojson`: inter-county border LineStrings (coast and bbox edge excluded), one feature per neighbouring
  county pair with props `{county, neighbor}`, simplified (≈ 40 m).
