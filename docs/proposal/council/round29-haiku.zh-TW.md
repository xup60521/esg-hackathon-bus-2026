## 3 新引入的錯誤與過度宣稱

1. **「repo 內的 summary.json」在 git 中不存在。** [事實] `git ls-files` 對 `docs/proposal/`、`scripts/lab/`、`public/data/` 的結果皆為 0，三者都是未追蹤（`??`）。H 與 PLAN §3、§6 所說「可由 repo 內 summary.json 重算」只在目前工作副本成立；以 git 交付的人拿不到這些檔案。
2. **「真實不確定性更寬」是未被支持的預測**（見 §1.3）。
3. **「各站區間（iid）已部分重疊」不正確。** [事實] 高組（桃米坑、暨南大學）與低組（九族、崎下）的 iid 區間不重疊（例如 5.7–9.2 與 3.2–5.6）；重疊只發生在組內。H 第 36 行的說法會讓讀者低估分隔程度，同時又高估不確定性。
4. **「資料權限可核對」（PLAN §3 A0 行）與權限未確認互相矛盾。** [事實] H 寫「目前未確認」；§3 的驗收欄卻寫「可核對」。
5. **「事件」用語衝突。** [事實] H 把「座位不多代理」到站稱為「事件」，PLAN 的主要指標「因客滿未上車事件」是另一個概念。讀者會把 H 的 7.2% 與主指標混在一起。建議改為「代理到站」。
6. **休息日的來源描述不精確。** [事實] `calendar.json` 的欄位說明為「rest=true 即是否放假=2（週休、國定假日、補假）；rest=false 為上班日，含補行上班日」，資料來源為行政院人事行政總處辦公日曆表（data.gov.tw/dataset/14718）。H 寫「假日與調整放假日」，與原文不符，也沒有列出機構與網址。
7. **§1 的 8.2% 沒有引用。** [事實] 「崎下 2025 年下半年有上游鏈結的到站中，約 8.2%（38 席情境，≥33）」出自 `drafts/forecast-experiment-v4.zh-TW.md` 的 3,044／250，但 PLAN §1 沒有連結，附錄 H 也沒有此數字。評審無法在提案包內追溯。
8. **2.9–3.2 pp 的上端應為 3.3**（見 §1.1），小誤差。
9. **H 的「事件」「分母」與 §4 的「分母僅有人刷卡上車的到站」一致**，但 H 沒有說明位置效應（§1.4），讀者可能把 0% 的終點站讀為「安全」。
