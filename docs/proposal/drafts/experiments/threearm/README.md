# 候選站篩選，尚未完成模擬

執行 `python3 -I screen.py /絕對路徑/trips.db > candidate-screen.csv`。程式只用標準庫，以 SQLite 唯讀模式開啟資料庫。輸出是探索性候選站篩選，不是三臂模擬。

規則固定為週日、臺灣時間 13:00 至 17:59:59，上車站為三個候選站之一、下車站為埔里站／高鐵臺中站／臺中，且下車時間晚於上車時間。日期以資料的 board_date 為準。這個條件沒有完整涵蓋往埔里方向所有目的地，也不含非週日休息日。統計的是成功刷卡的旅次；車號日期組合不是班次，到站事件、實際候車或未能上車均未計算。

尚缺同車多班辨識、站序與時間合理性檢查、到站事件配對、需求及服務假設、里程與空駛依據、逐站排隊與手算驗證。因此不得把這份篩選結果解讀為加班效果。
