## 各輪的主要轉折

1. **第 1 輪**：兩位評審一致建議把主打從「座位顯示＋加班專車」轉為「量測與在地驗證」，並指出影響力模型的暴露量用錯分母、碳門檻與 ESG 主張衝突。
2. **第 2 輪**：Haiku 以重算發現「預報」其實是上游載客規則（召回 100% 是構造性），三臂「零改善」是座位假設被資料推翻的結構性產物；因此改寫為上游即時載客警示與座位／時點敏感度分析。
3. **第 3 輪**：統計力顯示 G2 的 10% 改善在單站無法偵測，改為描述性試辦＋護欄；G1 改兩階段；先例（10 席）因無法直接連上業者網站而降級為「索引所述」。
4. **第 4 輪**：發現 G1 的樣本需求與 3–5 月時程不相容，把第一個可交付改為 G0 與影子運行；補上展示連結與對照日一致性、留站事件情境範圍。
