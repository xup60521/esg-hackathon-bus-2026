# 中途站載客預報實驗

舊版，預設路徑為開發副本，不作交付重跑指令。

從 repository 根目錄執行：

```sh
python3 -I docs/proposal/drafts/experiments/forecast/run.py /絕對路徑/trips.db
python3 -I docs/proposal/drafts/experiments/forecast/report.py
```

省略資料庫參數時使用任務指定的 `/tmp/claude-1000/-home-zup-code-esg-hackathon-bus-2026/e3280782-e84b-4051-8849-189e12c5a845/scratchpad/trips.db`。資料庫以 SQLite URI `mode=ro` 開啟，不依賴第三方套件；讀取 repo 的 `public/geo/stops.json`，只在本目錄寫 `results.json`，並在上兩層寫結論報告。約需數分鐘、足夠記憶體容納原始資料。固定亂數種子 20261111；300 次按驗證日整日重抽 bootstrap，區間為百分位數。模型固定，區間不含重新訓練的不確定性；無正例或無預警時指標未定義，區間只統計有定義的重抽樣本。

排除、同秒順序、同站連續上車合併均沿用 seats 模型。每個目標到站取同 vehicle、同日緊接前一筆不同站到站的最後上車時刻作預測時點，限制 0–30 分鐘、兩站均有不同站序；只用該時點當下已發生的上下車計數。目標為第一筆上車之前、同秒先下車的載客量。訓練 2024 至 2025-06，測試 2025-07 至 2025-12，依目標站分開訓練。A 的特徵是上游時點的星期與三小時時段對應之訓練期目標站平均載客，對小樣本向全站平均收縮 10 筆，再以邏輯回歸轉換成機率；B 加入上游最後一筆刷卡後的載客數。固定 0.5 門檻，不以測試集調參。容量 C 的「座位不多以上」門檻為 C−5。JSON 同時含每個機率區間的校準人數、平均機率與實際比例、Brier、整體預測與實際比例及其區間，和迴歸係數。

配對使用事後觀察到的下一筆目標站刷卡以定義評估樣本，並不表示預報當下能辨認該車確實會到目標站；連續不同站也不保證方向正確或同班次。必須另用實際班次、方向、GPS 驗證。僅有成功上車的站可配對，不能推廣至未停站及無刷卡上車的班次。訓練期特徵平均包含訓練樣本本身，留出期沒有這種洩漏，但可能影響模型擬合。上游站群組的最後刷卡時間為事後確定，線上系統需定義可觀測的發車時點；本結果不是可直接部署的即時準確率。
