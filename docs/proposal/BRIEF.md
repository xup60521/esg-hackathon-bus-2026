# 提案計畫工作簡報（所有協作者必讀）

## 任務
為「ESG 黑客松（公車主題）」擬定一份**可交付評審的完整提案計畫**。計畫將依四項標準被評分：

1. **提案完整性**：問題、目標族群、解法、執行步驟、時程、資源、風險、衡量指標、利害關係人是否齊備且前後一致。
2. **技術可行性**：資料、系統架構、演算法、整合、成本、法規能否在黑客松期間做出示範，並有可行的上線路徑。
3. **作品創新性**：相對於現有做法（台灣與國外）的差異化；創新要有根據，不誇大。
4. **預期社會影響力**：受益人群、規模、可量化指標、ESG（尤其 S 與 E）、可複製性、對不確定性的量化。

## 上一輪討論得到的候選創新方案（e103eb01）
主題：**「6670 不再過站不停」**。三層結構：
1. **讓問題看得見**：司機端「滿載過站」按鍵（參考溫尼伯）＋由刷卡即時推算車上人數。
2. **讓中途站上得了車**：三級即時座位資訊（有空位／座位不多／已滿）顯示在站牌與手機；中途站保留座；站牌顯示「已滿」時可一鍵預約下一班。
3. **尖峰有車可派**：只收預約的加開專車（正班維持現場上車，不分區）；預約者可挪移時間 ±60 分以湊成整車；與遊覽車業者簽待命加班協議（日本做法）。
配套：高鐵銜接保證（德國）、異常刷卡自動退款（倫敦）、長者與輪椅「上車預告」（英國 NCTX）、電話與櫃台預約。
