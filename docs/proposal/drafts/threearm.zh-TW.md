# 三臂比較：候選站初篩，模擬尚未完成

給評審：目前只能確認九族文化村在所選條件下有較多成功刷卡旅次，適合作為後續研究候選站。刷卡資料沒有記錄在站上等候或未能上車的人，也無法憑此判斷加車是否有效。三臂比較尚未完成，沒有可供簡報使用的加班效益數字。

篩選限下車時間晚於上車時間，使用臺灣時間；站名及目的地採資料原值。上述不是所有往埔里方向旅次，也不是需求總量，數字不代表到站數或留站人數。九族文化村的樣本較多，且 104 個週日有紀錄，因此暫選為研究對象。這不是證明九族最擁擠；其他站服務支線不同，限定目的地會影響比較。樣本選擇本身須在完成模擬前固定，不能用三臂效果挑選最有利的站或日期。

主要障礙是同一支線的同一站出現多個站序，同車同日也可能有多班；單靠車號與日期無法確認班次歸屬。需先定義並驗證到站事件與行車方向的配對，公開無法歸屬比例，再以一致的合成抵站及服務假設計算逐站先下車後上車。加班車公里及空駛還需要可追溯的路程與車輛起訖位置假設。實際座位與保留配額未經證實，不可填入真值；37／38／42／43 只能是情境，容量情境差異不是信賴區間。隱藏需求 h=0%／10%／25% 亦屬假設，h=0 並不能估計未觀測需求。

本次沒有完成三臂、各日 P10／P50／P90、候車時間、留站人數與事件、上下游影響、加班時刻及起點敏感度，也沒有計算車公里或成本。候選篩選的程式及輸出見 `experiments/threearm/`。
